# Types

Shared TypeScript contracts for:

- `trade-ops.ts` — declarations, HS codes, duty, permits, clearance, compliance
- `fiz-fcz.ts` — zones, tenants, gate passes, movements, bonded stock, exemptions
- `custom-agents.ts` — agent definitions, runs, handoffs, policies, audit, memory

Import via the barrel: `import type { TradeDeclaration } from '@/types';`
