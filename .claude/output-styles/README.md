# Output styles

| File | When to use |
|---|---|
| `tradeops-default.md` | Normal development work. |
| `regulatory-review.md` | Reviewing tariff, control, or compliance changes. |
| `declaration-review.md` | Reviewing a prepared declaration before sign-off. |

Set the active style via `settings.json` (`"outputStyle": "tradeops-default"`)
or `/config`.
